Part B provides scale-oriented FL evidence under controlled simulation. We ran FedAvg for 25 global rounds with non-IID client partitions generated by Dirichlet sampling ($\alpha=0.3$), using 3 seeds per setting and client counts \{2, 5, 10, 20\}.

\subsection{Synthetic Dataset}
To enable reproducible experiments without external dataset dependencies, we generated a synthetic dataset of $16\times16$ grayscale images spanning four waste categories (cardboard, glass, paper, plastic). Each class is defined by a distinct geometric prototype: horizontal stripes for cardboard, diagonal center-line patterns for glass, nested rectangular regions for paper, and vertical stripes for plastic. Individual samples are produced by a convex combination of the primary prototype (52\%), the next-class prototype (23\%), an alternate-class prototype (10\%), and the mean shared pattern (15\%), followed by additive Gaussian noise ($\sigma=0.30$), brightness jitter (8\%), stochastic pixel roll (35\% probability), and occasional class blending (12--17\%). This process yields 220 samples per class while maintaining visual separability, enabling reproducible non-IID partitions via Dirichlet sampling. The simulator can optionally load real TrashNet images if the corresponding directory structure is provided.

\subsection{Configuration}
Each run used local epochs $=2$, batch size $=16$, SGD with learning rate $0.18$, and full client participation per round.

\subsection{Convergence Results}
Across all settings, FL converged stably with final global accuracy near 93--94\% and no failed rounds. Mean final accuracy was 93.75\% (2 clients), 93.56\% (5), 93.37\% (10), and 93.75\% (20). Mean final loss ranged from 0.2192 (2 clients) down to 0.1933 (20 clients). Exact-permutation tests on final accuracy differences (2 vs 5, 5 vs 10, 10 vs 20) were not significant at $p<0.05$.

\subsection{Efficiency and Communication Trade-Off}
Mean round duration increased with scale from 0.005\,s (2 clients) to 0.008\,s (20 clients), while communication grew approximately linearly with client count. Total communication (sent+received) increased from 0.394\,MB (2 clients) to 3.941\,MB (20 clients). Consequently, accuracy-per-MB decreased from 2.38 to 0.24, illustrating the expected cost-accuracy trade-off as participation expands.

\subsection{Gradient Quantization}
\label{sec:quantization}

To address the communication bottleneck, we integrate stochastic rounding quantization into the FedAvg pipeline. After local training, each client quantizes its weight updates to a target bit width before transmission; the server dequantizes the received updates before weighted averaging. We evaluate two configurations: 8-bit (4$\times$ weight compression) and 4-bit with uint8 packing (2 values per byte, 8$\times$ weight compression). The total communication volume includes protocol overhead, so the observed reduction is approximately 1.59$\times$ for 8-bit and 1.77$\times$ for 4-bit packed at 20 clients.

These results demonstrate that lightweight gradient quantization is effective on resource-constrained edge hardware without compromising model quality.
