Two Arduino UNO Q nodes (Debian 13) ran the edge daemon against the shared backend during a $\sim$12-minute session. End-to-end ingestion was validated across Edge $\rightarrow$ MQTT $\rightarrow$ Backend $\rightarrow$ PostgreSQL $\rightarrow$ Frontend, persisting 282 MQTT rows (147 from \texttt{unoq-01}, 135 from \texttt{unoq-02}).

Both nodes successfully completed FL cycles (\texttt{Join}, \texttt{GetGlobalModel}, \texttt{SubmitUpdate}), reaching model version 26 with 25/30 successful aggregations (83.3\%). Five submissions were rejected as stale during concurrent updates, confirming correct monotonic round enforcement. Round submission latency was low (median $\sim$25\,ms, max 105\,ms). Mean local accuracy was 0.921 (\texttt{unoq-01}) and 0.871 (\texttt{unoq-02}). Both devices used \texttt{--fake-camera} and HTTP label injection to exercise FL deterministically; camera-in-the-loop latency is left for future work.
