Each Arduino UNO Q has a Qualcomm QRB2210 processor (Debian Linux) and an STM32U585 microcontroller, connected over Wi-Fi to a shared backend (MQTT broker, PostgreSQL, FastAPI REST API, gRPC FL coordinator). The edge daemon follows capture/classify/act logic using a MobileNetV2 TFLite model (classes: cardboard, glass, paper, plastic). User corrections are stored locally for on-device fine-tuning.

The trainable model is a frozen MobileNetV2 backbone with a small learnable head. After accumulating new labels, a node fetches global weights, trains locally, and submits an update via gRPC; the coordinator applies FedAvg~\cite{mcmahan2017fedavg}. Boards publish status and FL metrics to \texttt{arduino/<device-id>/\#} via MQTT.
