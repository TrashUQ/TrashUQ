TrashUQ combines real two-node Arduino UNO Q validation with controlled FL simulation. Real deployment confirmed persistent multi-node telemetry and FL coordination up to model version 26; simulation confirmed stable non-IID FedAvg convergence across 2--20 clients with final accuracy around 93--94\%. We further demonstrate that stochastic rounding gradient quantization provides 4--8$\times$ model compression with negligible accuracy loss (0--1.33\%), effectively mitigating the communication bottleneck identified in prior sections. Code is available at \url{https://github.com/TrashUQ/TrashUQ}; future work will focus on camera-in-the-loop latency validation and deployment of quantized models on Arduino UNO Q hardware.
